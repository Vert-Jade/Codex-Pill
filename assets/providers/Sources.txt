CODEX
Codex.png est une copie inchangée du PNG officiel OpenAI (Blossom), 180 × 180.
Ce fichier représente OpenAI, fournisseur de Codex. Aucun symbole propre à
Codex n'est revendiqué pour cette image.
Page de référence : https://openai.com/codex/
Image officielle : https://openai.com/apple-icon.png?apple-icon.3o0tf8iy4mx7y.png
Original SVG également conservé : https://openai.com/favicon.svg
Directives : https://openai.com/brand/
Le SVG de favicon contient des variables CSS et des variantes clair/sombre ;
le PNG officiel est utilisé pour éviter les différences de rendu des moteurs.
